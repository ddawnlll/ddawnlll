## things i built

low level

- [hhcc](https://codeberg.org/dawn_ll/hhcc) — holy holy c compiler. python + llvmlite.
- [hapl](https://codeberg.org/dawn_ll/hapl) — a language where every computational entity is semantically related. [vscode extension](https://github.com/ddawnlll/hapl-vscode).
- [risc-v kernel tutorials](https://codeberg.org/dawn_ll/riscv-kernel-development-tutorials) — riscv64 kernel development, written up and on video.
- [templede](https://codeberg.org/dawn_ll/templede) — a wayland desktop environment.
- [qc2-linux](https://codeberg.org/dawn_ll/quadcast2-linux-driver) — usb backlight driver for the quadcast 2 microphone.
- [raycord](https://github.com/ddawnlll/raycord) — p2p desktop chat. rust, raylib, tokio. ed25519 identity per peer, udp lan discovery, gossip sync over tcp.

agent tooling

- [praxis](https://github.com/ddawnlll/praxis) — checks whether an ai coding agent actually finished the task. evidence-gated. [docs](https://praxis-docs-site.netlify.app).
- [hephaestus](https://github.com/ddawnlll/hephaestus) — improvement loop for any codebase, built on praxis, with an explorer / red team council.
- [my-claude](https://github.com/ddawnlll/my-claude) — claude agent client in go, opencode compatible.

trading

- [v7-engine](https://github.com/ddawnlll/v7-engine) — quant engine: simulation, alpha discovery, rl policy critic, execution. strict domain boundaries.
- [quant-edge-lab](https://github.com/ddawnlll/quant-edge-lab) — research lab for finding (or not finding) an edge.

web and other

- [designforge](https://github.com/ddawnlll/designforge) — url in, redesign blueprint out.
- [gebzefiber2](https://github.com/ddawnlll/gebzefiber2) — site for a fiber-optic repair business. a real client. [live](https://ddawnlll.github.io/gebzefiber2/).
- [my-term](https://github.com/ddawnlll/my-term) — kitty, oh my zsh, starship.
